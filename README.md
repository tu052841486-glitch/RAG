# 藥你安心｜農藥博士

> 讓農民用對藥，也買對藥。

以檢索增強生成（RAG）為核心的農藥知識問答系統。整合農業部農藥登記資料、農藥法規與經濟部商工行政開放資料，
讓農民與在田間工作的外籍移工，用母語提問或拍一張照片，就能查到「在台灣合法、數字正確」的用藥資訊。

- 前端：<https://pesticide-doctor-frontend.vercel.app/>
- 後端 API 文件：<https://pesticide-doctor-api.fly.dev/docs>
- 系統健康檢查：<https://pesticide-doctor-api.fly.dev/health>
- 資料更新紀錄：<https://pesticide-doctor-api.fly.dev/api/data/status>

2026 大專校院資訊應用服務創新競賽（AI 工具運用組、商業治理 AI 創新組）決賽作品。

---

## 核心設計：數字不經 AI 生成

生成式 AI 只負責理解問題、改寫追問與白話說明；稀釋倍數、一桶水加藥量、施藥間隔、安全採收期、噴藥排程與廠商資料，
一律由資料庫、演算法與官方 API 產生，從架構上避免 AI 編造攸關安全的數字。

## 服務對象

| 角色 | 使用者 | 主要功能 |
| --- | --- | --- |
| 決策者 | 本國農民、雇主 | 問答、拍照判讀、處方卡、合法性檢查、販賣業者查詢 |
| 執行者 | 農業外籍移工（印尼、越南、泰國、菲律賓） | 以母語查詢每桶加藥量、防護方式與中毒急救 |
| 學習者 | 農藥證照考生、農藥行從業人員、青農 | 模擬考、學習教材 |
| 管理者 | 農會、改良場、地方政府 | AI 治理儀表板、病害通報熱區 |

## 功能：七步驟用藥鏈

| 步驟 | 功能 | 說明 |
| --- | --- | --- |
| ① 認病 | 拍照判讀 | 三級判定（健康／疑似異常／明顯病徵）與拍照品質檢查；使用者確認後才查詢用藥 |
| ② 選藥 | RAG 智慧問答 | 混合檢索官方資料，以農會指導員口吻回答；支援連續追問與作物俗名 |
| ③ 確認合法 | 用藥合法性檢查 | 農藥未登記於該作物，第一句就回答「不可以」 |
| ④ 買對藥 | 廠商查核、販賣業者查詢 | 查核登記廠商是否營業中；依鄉鎮列出登記農藥零售／批發的公司 |
| ⑤ 排好怎麼噴 | 輪替用藥計畫 | 演算法依安全採收期、施藥間隔、施用次數與作用機制排出噴藥日期 |
| ⑥ 用對量 | 用藥處方卡 | 稀釋倍數、一桶 16 公升加藥量、安全採收期，數值直接取自資料庫 |
| ⑦ 資訊正確 | 資料自動更新 | 每週同步官方登記資料與法規，失敗自動重試，具異常防護與更新紀錄 |

另提供農藥資訊卡、學習教材、模擬考（含錯題本）與會員對話紀錄。

## 多語服務

介面與回答支援 **中文、Bahasa Indonesia、Tiếng Việt、ภาษาไทย、English、日本語**。

- 外語問題先翻譯成中文檢索；回答以中文產生後再翻譯，檢索、合法性檢查、拒答判斷與所有數字都不受影響。
- 藥名保留中文原名（例如 trifloxystrobin（三氟敏）），方便拿著手機到農藥行對照購買。
- 外語回答固定標示「AI 翻譯，用藥以中文農藥標籤為準」。

## AI 治理

| 原則 | 做法 |
| --- | --- |
| 人在迴路中 | AI 只提出候選，使用者確認後才查詢用藥、才計入病害熱區 |
| 數字不經 AI | 藥名、倍數、天數、加藥量一律取自登記資料或由程式計算 |
| 規則把關 | 信心不足的「明顯病徵」自動降級；含農藥領域詞的問題不允許被誤判為無關 |
| 資料最小化 | 不保存照片、不綁定帳號，位置自願填寫且只記錄到鄉鎮 |
| 去識別化 | 區域通報未滿 3 筆不顯示數字 |
| 可稽核 | 每次判讀記錄時間、模型、等級與使用者回應；管理端儀表板 `/governance` 可查閱 |

## 系統架構

```
React 前端（Vercel）：問答、拍照判讀、六語切換、系統狀態燈
   │  REST API
FastAPI 後端（Fly.io，Docker，記憶體 2GB 常駐）
   ├─ rag.py         混合檢索、合法性檢查、處方卡、主題判斷與規則把關、多語翻譯
   ├─ tokenizer.py   自建中文斷詞（詞典取自官方登記資料，不依賴第三方斷詞套件）
   ├─ vision.py      拍照判讀（三級判定、拍照品質檢查、輸出防護）
   ├─ diagnosis.py   判讀紀錄、病害通報熱區、AI 治理儀表板
   ├─ planner.py     輪替用藥計畫
   ├─ gcis.py        農藥廠商查核（商工行政資料開放平臺）
   ├─ dealers.py     合法農藥販賣業者查詢（商工行政資料開放平臺）
   ├─ updater.py     資料自動更新（農藥登記、法規），失敗自動重試
   ├─ health.py      健康檢查（SQLite、ChromaDB、OpenAI）
   ├─ auth.py / conversations.py   帳號與對話紀錄
   └─ db.py          SQLite（結構化資料）、ChromaDB（向量資料庫），存放於 Fly 持久化磁碟
```

- 檢索：SQLite 精準查詢＋向量語意檢索（text-embedding-3-small）＋BM25 關鍵字檢索，以 RRF 融合排序
- 生成式 AI：GPT-4o（問答、影像辨識）、GPT-4o-mini（主題判斷、追問改寫、翻譯）
- 模型以環境變數設定（`ANSWER_MODEL`、`VISION_MODEL`），模型更替時不需修改程式

## 品質驗證

`test_accuracy.py` 對線上系統執行 11 題標準測試，涵蓋用藥、安全、法規與知識邊界四類，
逐題檢查拒答判斷、回答內容、來源卡片與處方卡，並檢查 AI 是否自行假設數字。目前通過 11／11 題。

## 本機啟動

### 後端

```
pip install -r requirements.txt
cp .env.example .env          # 填入 OPENAI_API_KEY、ADMIN_TOKEN
python build_db.py            # 建立 SQLite 資料庫
python build_index.py         # 建立向量索引（約 3–5 分鐘）
uvicorn main:app --reload --port 8000
```

### 前端

```
cd frontend
npm install
npm start                     # http://localhost:3000
```

## 部署

- 後端：`flyctl deploy -a pesticide-doctor-api`（資料存放於持久化磁碟，重新部署不會覆蓋）
- 前端：推送至 GitHub 後由 Vercel 自動建置

## 注意事項

本系統資訊僅供參考，實際用藥請依農藥標示；營業項目登記不等於持有農藥販賣業執照，購買前請確認店家執照與農藥許可證字號。
